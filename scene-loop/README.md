# SceneLoop · 미드·영드 실전 쉐도잉 스튜디오

프렌즈 · 모던 패밀리 · 오티스의 비밀 상담소의 **실제 유튜브 클립**으로 구간 반복 쉐도잉을 하는 모바일 웹앱입니다.
문장마다 화자 · 영어 대사 · 한국어 번역 · 핵심 표현(이디엄) 해설이 붙어 있고, 영상 구간을 3·5·10회 반복하거나
음성만 3·5·10·∞회 반복하며 따라 말할 수 있습니다.

- 앱 주소(로컬): `repos/daily-radar/scene-loop/index.html`
- `file://`로 열어도 동작합니다(데이터·폰트 인라인). 유튜브 재생만은 http로 열 때 가장 안정적입니다.
- GitHub Pages 배포는 **하지 않았습니다** (로컬 검토용, git commit/push 없음).

## 기능

**▶ 실제 영상 학습**
- `▶ 3회 / 5회 / 10회` 구간 반복 (문장 시작→끝)
- `🎬 전체 씬 보기` — 클립 시작부터 끊김 없이 재생하며 현재 대사 자동 추적
- `⏹️ 멈춤`, `유튜브 앱 ↗`(해당 문장 시점으로 이동), `다른 영상 URL`(영상만 교체)
- 구간 여백 `기본 / +3초 / +6초` — 문장 끝이 잘릴 때
- 속도 5단계 `0.8 · 0.9 · 1.0 · 1.1 · 1.2x` (영상 배속 + 음성 배속 동시 적용)
- 억양 4종 `🇺🇸미국 · 🇬🇧영국 · 🇦🇺호주 · 🇮🇳인도` — 오티스는 기본값이 🇬🇧
- 전체 대사 리스트: 화자·타임코드·영어(핵심 표현 하이라이트, 탭하면 해설)·한국어, 줄별 ▶ 재생 · ★ Hard

**🔊 음성 집중**
- 음성만 `3회 · 5회 · 10회 · ∞ 무한` + `⏹️ 멈춤`, 회차별 1.5초 따라 말하기 간격
- 한 번만 듣기, 이전/다음 대사 이동, 같은 속도·억양 칩

**🔥 Hard · 보관함 & 퀴즈**
- ★ Hard 문장(및 내 문장)을 `localStorage`에 저장 → 앱을 닫아도 유지
- 보관함에서 바로 재생, Hard 4문장 이상이면 **4지선다 퀴즈** (영어→한국어 / 한국어→영어 전환)

**＋ 내 문장 · 유튜브 URL · JSON**
- 내 문장 추가(영어·한국어·영상 URL) → 하단 바
- 유튜브 URL/ID로 영상만 교체
- Hard·내 문장·퀴즈 기록 JSON 내보내기/불러오기(클립보드 복사, 파일 저장)

**기타** — 핀치 줌 허용, 다크 SceneLoop 테마, 하단 고정 바, 앱 아이콘(클래퍼보드+반복 화살표+`5×`) 180/512, `manifest.json`(홈 화면 추가).

## 타이밍과 대사의 출처

1. 유튜브 로그인 세션으로 각 영상의 **스크립트 패널**(`스크립트 표시`)을 열어 큐 시작 시각과 원문을 그대로 읽었습니다.
2. 자동 자막(ASR) 클립은 문장부호·고유명사·오인식(“it's gonna be very bad for the games” → “the gays” 등)을 **실제 대사로 교정**했습니다.
3. 한 큐에 여러 화자의 대사가 붙어 있는 경우, 큐 시작 시각을 기준으로 **말 길이에 비례해 나눠** 시작/끝 시각을 잡았습니다(`content.py`).
   따라서 큐 경계 시각은 유튜브 값 그대로이고, 큐 안에서 나눈 문장의 시각은 ±1초 안팎의 오차가 있을 수 있습니다.
   문장 끝이 잘리면 화면의 `구간 여백 +3초`로 보정하세요.
4. 영상 길이는 유튜브 메타데이터 값이며, 대사가 영상 끝을 넘지 않도록 클램프합니다.

## 파일 구조

```
scene-loop/
├── index.html          # 배포/열람용 단일 파일 (데이터·폰트 인라인)
├── app.template.html   # 원본 템플릿 (__FONT_*__, /*__DATA__*/ 자리표시자)
├── data.json           # 쇼 3개 · 클립 8개 · 문장 143개
├── content.py          # 대사 원본 + data.json 생성기 (끝 시각 자동 계산)
├── build.py            # data.json + 템플릿 → index.html
├── make_icons.py       # 아이콘 생성 스크립트
├── icon-180.png · icon-512.png
├── manifest.json
├── font-reg.woff · font-bold.woff   # 라틴 임베드 폰트
└── README.md
```

빌드: `python3 content.py && python3 build.py` (아이콘은 `python3 make_icons.py`)

### 알아 둘 점

- 이 검증 환경은 데이터센터 IP라 유튜브 재생이 **모든 영상에서 코드 150**으로 막힙니다(대조군 영상도 동일).
  이때 앱은 영상 화면(썸네일)은 그대로 두고 플레이어 아래에만
  “⚠️ 이 영상은 앱 안 재생이 막혀 있어요(코드 150). 유튜브 앱 ↗으로 열면 같은 구간부터 볼 수 있어요.”를 표시하며,
  대사 목록·구간 선택·음성 반복은 그대로 동작합니다.
  실제 휴대폰에서는 공식 채널 클립이라 임베드 재생이 정상이며, `onReady`까지 확인했습니다.
- 일부 클립은 자동 자막만 제공되어 대사를 직접 교정했습니다. 오탈자를 발견하면 `content.py`의 해당 줄을 고치고 다시 빌드하세요.
