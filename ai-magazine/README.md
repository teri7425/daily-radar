# AI 매거진 데스크 (AI Magazine Desk) — 로컬 시안

매일 오전 9시에 갱신되고 일요일 오전 9시에 한 주를 결산하는 모바일 매거진 웹앱입니다.
케인리님 검토·승인 전 **로컬 전용** 초안이며, 아직 `git commit`/`push` 하지 않았습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 (HTML + CSS + JS 단일 파일, 외부 의존성 없음) |
| `manifest.json` | 홈 화면 추가(PWA)용 매니페스트 |
| `icon-192.png` / `icon-512.png` / `icon-180.png` | 홈 화면 아이콘 |

## 3개 탭

1. **📰 오늘의 매거진** — 12건 카드 + "오늘 케인리님께 추천하는 앱/활용법" 하이라이트. 카테고리 필터 칩(전체/업무/개인·가족/아이디어·앱/트렌드·툴)과 키워드 검색.
2. **🗓️ 일요 주간 결산** — 이번 주(11/23~11/29) 실제 보도 7건, 3개 테마, 최종 이용 추천 TOP 3.
3. **⭐ 내 찜 목록** — 찜한 카드 + 카드별 메모 + "지안아, 이거 만들어줘" 클립보드 복사.

## 카드 필드

제목 · 요약 · **케인리님 적용 포인트** · 출처명 + 실제 링크 · 카테고리 태그 · 날짜.
데이터는 `index.html`의 `const CARDS = [...]` 배열 하나에서 관리합니다. 항목을 추가하려면 같은 형태의 객체를 넣으면 카드 수·필터 카운트·찜 목록이 자동으로 따라갑니다.

주간 결산 데이터는 `const WEEK = [...]`, TOP 3는 `view-sunday` 섹션 안의 마크업입니다.

## 저장 방식

- 찜: `localStorage["amd_bookmarks_v1"]` (id → true)
- 메모: `localStorage["amd_memos_v1"]` (id → 문자열)
- 마지막 탭: `localStorage["amd_lastTab_v1"]`

## 콘텐츠 출처 원칙

- 2025.11 ~ 2026.11 공개 글·게시물 중 원문을 직접 열어 확인한 것만 수록했습니다.
- 인스타그램 카드는 해당 계정의 실제 게시 내용을 요약했고, 계정 링크는 로그인 없이 열리지 않을 수 있습니다.
- 요약은 원문의 주장이며, 수치는 원문 표기를 그대로 옮겼습니다.
