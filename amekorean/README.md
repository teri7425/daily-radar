# 🇺🇸 아메리코리아노 5회 반복 트레이너

`@amekorean`(아메리코리아노) 채널의 실제 강의 영상에서 뽑은 영어 문장을 **5회 반복**으로 듣고 따라 말하는 모바일 학습 앱입니다. `index.html` 한 파일로 동작하며, 인터넷이 없어도(`file://`) 열립니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (데이터가 안에 들어 있어 단독 실행 가능) |
| `data.json` | 학습 데이터 — 영상 9편 / 문장 172개 + 전체 147편 카탈로그 |
| `app.template.html` | HTML 원본 (수정은 이 파일에서) |
| `build.py` | `data.json` + 템플릿 → `index.html` 생성 (폰트·데이터 인라인 주입) |
| `icon-180.png` / `icon-512.png` | 홈 화면 아이콘 (미국 국기 + 태극 + `5×` 배지) |
| `manifest.json` | 홈 화면에 추가할 때 쓰는 정보 |

```bash
python3 build.py     # 데이터나 템플릿을 고친 뒤 항상 실행
```

## 쓰는 법

1. 상단 탭에서 **🔥 Hard / 회화 / 패턴 / 문법 / 전치사 / 동사 / 📚 전체** 중 하나를 고릅니다.
2. 문장을 누르면 아래 패널에 영어·한국어가 뜹니다.
3. **▶ 영상 구간 5회** — 유튜브 원본에서 그 문장 구간만 5번 반복(사이 2.3초 따라 말하기).
   **🔊 음성만** — TTS로 3·5·10회 또는 ∞ 무한 반복.
4. **속도** 0.8 ~ 1.2x (영상·음성 공통), **TTS 억양** 미국·영국·호주·인도.
5. **☆ 어려움 체크** → 🔥 Hard 탭에 모이고, 브라우저(`localStorage`)에 남습니다.
6. **＋ 내 문장 / JSON 불러오기 / 내보내기** — 직접 문장을 넣거나, 새로 추출한 JSON을 합치거나, 내 학습 기록을 백업합니다.

## 데이터 늘리기

`data.json`의 `videos`에 영상을 추가하고 `allVideos`에서 해당 `extracted`를 `true`로 바꾼 뒤 `python3 build.py`.

```json
"videos": {
  "영상ID": {
    "title": "영상 제목", "category": "회화",
    "sentences": [{ "en": "I'm running late.", "ko": "나 늦었어.", "start": 210, "end": 218 }]
  }
}
```

> `start`/`end`는 초 단위. 앱에서 영상 반복과 TTS가 이 값을 씁니다.

### 문장 출처에 대해
문장과 타임스탬프는 유튜브 **한국어 자동 자막**에서 옮긴 뒤, 자동 자막 특유의 오인식(`I'm gna → I'm gonna`, `bathom → bathroom` 등)만 손으로 바로잡았습니다. 한국어 뜻은 영상에서 설명한 뉘앙스를 짧게 옮긴 것입니다.
