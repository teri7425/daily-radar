# ✈️ 소리튠 해외여행 영어 — 영상 5회 반복 트레이너

`@soritunenglish`(주아쌤_소리튠영어)의 **실제 여행영어 영상 6편**에서 뽑은 문장 255개를, 유튜브 원본 영상의 해당 구간을 **5회 반복**하며 따라 말하는 모바일 학습 앱입니다. `index.html` 한 파일로 동작하며, 인터넷이 없어도(`file://`) 열립니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (데이터·폰트가 안에 들어 있어 단독 실행 가능) |
| `data.json` | 학습 데이터 — 영상 6편 / 문장 255개 + 여행영어 영상 34편 카탈로그 |
| `app.template.html` | HTML 원본 (수정은 이 파일에서) |
| `build.py` | `data.json` + 템플릿 → `index.html` 생성 (폰트·데이터 인라인 주입) |
| `icon-180.png` / `icon-512.png` | 홈 화면 아이콘 (비행기 + 지구본 + `5×` + SORITUNE) |
| `manifest.json` | 홈 화면에 추가할 때 쓰는 정보 |

```bash
python3 build.py     # 데이터나 템플릿을 고친 뒤 항상 실행
```

## 쓰는 법

1. 상단 탭에서 **🔥 Hard / 공항·기내 / 호텔·숙소 / 식당·카페 / 쇼핑·결제 / 교통·길찾기 / 관광·명소 / 긴급·기타 / 📚 전체** 중 하나를 고릅니다.
2. 문장을 누르면 아래 패널에 영어·한국어가 뜨고, **402문장에 같은 문장이 있으면 초록 배지**로 어느 챕터인지 알려 줍니다.
3. **▶ 영상 구간 5회** — 유튜브 원본에서 그 문장 구간만 5번 반복(사이 2.3초 따라 말하기).
   **🔊 음성만** — TTS로 3·5·10회 또는 ∞ 무한 반복.
   **구간 여백** — 영상 끝이 살짝 잘리는 문장은 `+3초` / `+6초`를 눌러 그 문장만 더 길게 들을 수 있습니다(브라우저에 저장).
4. **속도** 0.8 ~ 1.2x (영상·음성 공통), **TTS 억양** 미국·영국·호주·인도.
5. **☆ 어려움 체크** → 🔥 Hard 탭에 모이고, 브라우저(`localStorage`)에 남습니다.
6. **＋ 내 문장 / JSON 불러오기 / 내보내기** — 직접 문장을 넣거나, 새로 추출한 JSON을 합치거나, 내 학습 기록을 백업합니다.
7. 📚 전체 탭에서 **✅ 추출 완료 / ⏳ 미추출 / 카테고리** 필터와 제목 검색을 쓸 수 있습니다.

### 타임스탬프와 영어 원문에 대해

- 문장·타임스탬프는 유튜브 **한국어 자동 자막(스크립트 패널)** 에서 옮겼습니다.
- **영어가 깨끗하게 잡히는 영상**(`IwI5qkUAIx8`, `HLpA-MMbxHY`)은 자막의 영어 문장을 그대로 썼고, **한국어 자동 자막이 영어 발화를 한글로 받아쓴 영상**(50문장 시리즈)은 한국어 해설과 발화 조각을 근거로 원문 문장을 복원했습니다. (`bathom → bathroom` 같은 자동 자막 오인식 보정과 같은 성격)
- `start`는 그 문장의 **한국어 해설이 시작되는 지점**, `end`는 **다음 문장 해설 직전 + 3초 여유**(영어 발화가 늦게 끝나면 그 지점까지)입니다. 영상 구조가 `한국어 해설 → (쉬는 시간) → 영어 발화 2~3회`라서, 처음엔 `start + 3~6초`로 잘랐다가 영어가 잘리거나 한국어만 나와 **2026-11-24에 구간을 다시 계산**했습니다(문장당 7~31초, 중간값 약 21초).
- 같은 문장이 영상에서 5~6번 반복되는데, 어떤 회차는 한국어 해설만 나오고 영어가 뒤따르지 않습니다. 그래서 한글 해설만 들리던 문장 45개는 **영어 발화가 확실히 들리는 회차로 옮겨** 잡았습니다(전체 255문장 중 226문장 = 89%가 구간 안에 영어 발화가 자막으로 확인됨).
- 재계산은 유튜브 스크립트 패널의 자동 자막 세그먼트(시각+텍스트)를 받아, 문장마다 한글 큐 위치를 다시 찾고 그 뒤 영어가 끝나는 곳까지로 `end`를 늘리는 방식입니다(`work/soritune-video/align.py`, 원본 세그먼트 `work/soritune-video/transcripts.json`).
- 자동 자막이 영어 발화를 아예 받아쓰지 못한 구간은 위치만으로는 확인할 수 없어, 구간을 **다음 한국어 해설 직전까지 넓게** 잡아 영어가 들어오도록 했습니다. 그래도 한 문장이 짧게 느껴지면 앱의 **구간 여백 +3/+6초**로 늘리면 됩니다.

## 데이터 늘리기

`data.json`의 `videos`에 영상을 추가하고 `allVideos`에서 해당 `extracted`를 `true`로 바꾼 뒤 `python3 build.py`.

```json
"videos": {
  "영상ID": {
    "title": "영상 제목", "category": "공항·기내",
    "sentences": [
      { "en": "Where is the baggage claim area?", "ko": "수화물 찾는 곳은 어디인가요?", "start": 112, "end": 116 }
    ]
  }
}
```

- 문장마다 `cat`을 넣으면 영상 하나를 여러 탭으로 나눌 수 있습니다(예: 관광지·길거리편 → 관광·명소 / 교통·길찾기 / 긴급·기타).
- `ref402`에 챕터 번호를 넣으면 초록 배지가 표시됩니다.
- `start`/`end`는 초 단위. 앱의 영상 반복과 TTS가 이 값을 씁니다.
